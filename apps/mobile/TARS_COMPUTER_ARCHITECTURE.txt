TOOL EXECUTION PIPELINE:

    User Message
         ↓
    AI Agent Processing
         ↓
    ┌────────────────────────┐
    │ Tool Execution Needed  │
    └────────────┬───────────┘
                 ↓
    ┌────────────────────────────────────────┐
    │ Tool Call Created                      │
    │ (e.g., 'web-search', 'execute-command')│
    └────────────┬─────────────────────────────┘
                 ↓
    ┌────────────────────────────────────────┐
    │ Snapshot created & added to timeline   │
    │ (toolCallSnapshots array)              │
    └────────────┬─────────────────────────────┘
                 ↓
    ┌────────────────────────────────────────┐
    │ RightPanel receives update             │
    │ (toolCallSnapshots, isGenerating, etc.)│
    └────────────┬─────────────────────────────┘
                 ↓
    ┌────────────────────────────────────────┐
    │ ToolView selector matches tool name:   │
    │                                        │
    │ 'browser-navigate-to' → BrowserToolView │
    │ 'execute-command' → CommandToolView    │
    │ 'read-file' → FileOperationToolView    │
    │ 'web-search' → WebSearchToolView       │
    │ etc. (see ToolViewRegistry)            │
    └────────────┬─────────────────────────────┘
                 ↓
    ┌────────────────────────────────────────┐
    │ ToolView Rendered with Result          │
    │ • Screenshot                           │
    │ • Terminal output                      │
    │ • File content                         │
    │ • Search results                       │
    └────────────┬─────────────────────────────┘
                 ↓
    AI continues with tool results in context
         ↓
    Response sent to chat
